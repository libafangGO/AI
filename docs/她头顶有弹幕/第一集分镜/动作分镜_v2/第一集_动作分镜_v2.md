## 一、这版怎么使用

- 故事层：沿用原24镜头的情节与六条心声。
- 生成层：拆为V01–V32，共32个可独立生成、独立重试的视频片段；每段只处理一个主动作或一个明确的表情变化。
- 剪辑层：按表格顺序组装为82秒预算；相邻同机位片段可以连成一个成片镜头，32个生成片段不等于必须有32次剪切。
- 关键帧层：每段明确开始和结束，共64个首尾位置；6处复用相邻尾帧，另列4个动作转折参考，合计62个不同画面状态定义。这是设计清单，不是已经生成62张图，也不要求开工前全部画完。
- 成片目标：16:9横屏、1920×1080、25fps；源视频可以按模型支持的分辨率、帧率生成，后期保持动作时长再统一规格。
- 时间口径：原75秒是静态预算；本版把推纸、移玉、翻纸和走位补完整，暂增至82秒。所有时间仍需通过画面样片与配音实测校准。

建议阅读顺序：先看“片段总表”，再看V24–V27的走位拆解，之后按具体片段制作关键帧和试片。

## 二、ComfyUI执行约定

已知环境：用户使用本地ComfyUI，模型称呼为“minmax H2”，硬件为“4080 + 48G内存”。用户回复尚未测试。准确模型文件名、节点实现、显存、原生帧率和首尾帧能力均未核实；48G内存不应直接当作48G显存。这里不把该称呼等同于任何已确认的模型能力，也不判断实际推理发生在本机还是API。

### 生成时长与成片时长分开

31段暂按5秒素材规划，V22的完整三句愿望暂按10秒素材规划，总首轮素材预算165秒，选取其中82秒；不含重试。这是排片预算，不是对当前ComfyUI节点可运行时长的保证。

每段建议在素材开头留约0.4秒稳定状态，再在表中指定的动作窗口里完成主动作，余下时间停稳。若成片只用2秒，主动作就应在这2秒窗口内完成；不能生成一个持续5秒的动作，再靠随意截掉中间或机械加速来凑2秒。

素材入点0.4秒和各段出点均为动作排布目标，不是已存在视频的剪辑点。生成后按实际合格帧重新标记。表内成片时间码采用25fps整数帧，出点为不包含的下一帧。

### 按工作流支持能力输入

仅支持首帧图生视频：输入本段首帧与动作提示词；尾帧描述用于验收，不把一张“想要的尾帧”当成模型会自动服从的输入。若动作做不完整，缩短动作或继续拆段。

支持首尾帧：输入审核过的首、尾两张图与动作提示词。起终状态应属于同一空间和身体动作，不能要求人物从椅子瞬间出现在沙发；中间动作仍需验收。

明确支持多关键帧：可按该节点的实际时间位置使用动作转折参考。K01M、K19M、K26M、K29M不默认属于必填模型输入，不能因为文档列了三张图就强行塞给双帧节点。

同机位接续：先验收前一段，再从前一段实际视频选出满足结束状态的尾帧，作为后一段首帧。仅使用同一个随机种子或同一份提示词，不能保证脸、手和道具连续。

不同机位切换：重新制作对应机位的首帧，用上一段尾帧核对姿态、道具和位置；不能把原机位的尾帧直接当成新机位构图。两段可正常硬切，不必强求每次都做无缝运镜。

### 未测试工作流的起步方式

先用V17“从营业笑到真满意”测试人物身份与小表情，再用V10“把玉佩移开”测试手和道具，然后用V24“站起”与V26“取枕”测试身体和接触动作。每次只换一个因素，记录工作流、模型文件名、分辨率、帧数、原生帧率、种子、峰值显存和耗时。

先沿用当前工作流可用的低分辨率和最短可用帧数做动作测试，不直接把1080p成片规格填成生成参数。模型节点允许的帧数、分辨率步长和是否可延长，必须以实际节点为准；测试画面清楚、动作完整后再延长或提高分辨率。

若V22不能稳定得到完整5秒有效画面，可拆为V22a的前两句愿望与V22b的“床最好归我”，拼接后仍占5秒预算；届时更新片段表为33段，不假装32段设计完全无需调整。

当前所有公开对白镜头都属于无声表演预演；画面中的说话嘴型不算正式口型同步。配音试读后，需要按工作流能力做口型处理或重生成相关段。心声镜头则必须保持闭嘴。纸上标题、玉佩微光、弹幕和字幕均在后期添加。

## 五、逐片段动作分镜

### V01｜推纸触玉｜原EP01-01

剪辑预算：0–2秒，使用2秒（50帧）。素材预算5秒；目标动作窗口0.4–2.4秒。

机位：桌面特写；男主右手从画面右侧进入；固定。

首帧 K01S：一张浅色约定纸正面朝上，位于桌中央偏男主一侧；实心浅青椭圆玉坠和旧红绳在纸右侧；一支黑笔在纸右下方。男主右手准备推纸，手腕尚未碰到玉坠。

动作顺序：

- 1. 手掌把纸朝女主方向平推约一掌宽，纸保持贴桌。
- 2. 同一次推纸动作中，右手腕轻碰玉坠，玉坠只滑动少许。
- 3. 手停下；玉坠的短暂微亮交给后期，底片不生成持续发光。

转折参考 K01M：纸正在平移，右手腕刚接触椭圆玉坠；同一只手同时完成推纸和轻碰，无多余手指。

尾帧 K01E：纸在两人之间平放；玉坠仍在纸右侧；右手停在纸边，黑笔未动。

公开对白：沈既白：婚后……

心声：无。

声音：纸张摩擦；极轻的玉佩提示音。

衔接：纸停止滑动后切V02双人中景；“婚后……”的声音延续到下一段，保留同一室内底噪。

输入方式：首帧图像与动作提示词；尾帧为可选输入/验收目标，中间帧不默认是节点输入。

重做条件：纸悬浮、红绳穿手、玉坠变成圆环或发光球、笔位置跳动。

### V02｜认真提出约定｜原EP01-02

剪辑预算：2–4秒，使用2秒（50帧）。素材预算5秒；目标动作窗口0.4–2.4秒。

机位：双人中景；女左男右；固定。

首帧 K02S：两人已坐好；女主双手轻叠桌边，男主右手在刚推完的纸旁。纸平放，男主没有重新举起纸。

动作顺序：

- 1. 男主抬眼看女主，肩背端正，像准备开会。
- 2. 说“我有三条要求”，句末稍停；女主保持礼貌注视。

尾帧 K02E：男主看向画面左的女主，手仍在桌上；女主准备回应。

公开对白：沈既白：我有三条要求。

心声：无。

声音：延续室内底噪，音乐轻进入。

衔接：在女主轻吸气准备回答时切V03；不要把双方两次抬头重复播放。

输入方式：首帧图像与动作提示词；尾帧为可选输入/验收目标，中间帧不默认是节点输入。

重做条件：男主突然拿起纸、双人左右互换、女主抢着说话或座椅位置变化。

### V03｜营业式回应｜原EP01-03

## 六、关键帧制作与拼接

### 先做哪些帧

先制作角色与动作试片需要的K17S／K17E、K10S／K10E、K24S／K24E、K26S／K26E；在节点能力确认前，尾帧是目标参考，并非必需的节点输入。通过人物、手部、起身和取枕测试后，再按片段顺序补齐素材。

关键帧清单中的62个状态包含26个独立首帧、32个尾帧和4个动作转折参考。微表情或对白段的尾帧可由生成视频选取；必须精准拿放道具的段落，可先画首尾帧帮助约束动作。所有图片应为单画面16:9，保留与生成分辨率一致的裁切范围，不能把六格拼版拉伸成单幅底图。

### 六处可以承接的同机位边界

- V08 → V09：公开回答完成、嘴闭合后进入心声。
- V10 → V11：玉坠已放好，空手转去拿笔。
- V18 → V19：划线后笔已放下，接翻纸。
- V24 → V25：起身站稳，接走向床尾。
- V28 → V29：开心已经转为疑惑，接抬手摸嘴。
- V30 → V31：枕头已放下，接收手与藏笑。

以上六处优先从前段实际合格尾帧接续。剪辑时删去重复停顿或重复动作，先试听与查看接点；如果身体姿态、光线或道具不匹配，修正该段或用合理切镜，不靠长叠化掩盖错位。

### 生成与验收顺序

先完成少量代表段试片并保存可复用的ComfyUI工作流；再完成对话与反应段；最后做手部和走位段。凡标注复用的后一段，都等前段合格后再生成。即使批量生成，文件名也按V01–V32编号保存，不能仅靠创建时间排序。

建议文件名：EP01_V24_take01_workflow.json、EP01_V24_take01.mp4、EP01_V24_take01_last.png。导出末帧时同时记录源视频文件名、实际帧号和时间，便于重试后替换。未确定扩展节点能力前，不绑定某个特定的读视频或存图节点名称。

验收每段时，同时播放开头、动作转折和结尾：确认脸、发型、手部、道具数量、运动方向、眼神与闭嘴规则。某段不能只因最后一帧好看就算合格；主动作必须真正发生，不能只做镜头缩放。

## 七、剪辑、心声和后期

六条心声依次位于V04、V09、V13、V17、V22、V29。前五条男主能读取；V29时男主已背对女主，只让观众听到。不要在V29之后加“他看见新弹幕”的眼神镜头。

喜剧反馈保持三条完整链：V04心声 → V05发现 → V06验证闭嘴 → V07追问；V13差评 → V14停顿 → V15改口；V22想要床 → V23决定 → V24–V27让床行动 → V28–V29惊喜转疑惑。

先组无声动作粗剪并核对道具与动作，再进行配音试读。公开对白和心声不得同时争抢听觉；长心声按语意分拍显示。心声区在人物头顶或侧上方，正式对白字幕在下方安全区，不遮嘴部和手部动作。

原生视频帧率若不同于25fps，在剪辑或导出时保持原动作时长再统一帧率；不要直接把帧率标记改成25而改变快慢。声音和动作校准后，再决定是否需要补帧、局部重生成或延长反应停顿。

82秒是当前预算。若正式语音读不完，优先给关键对白与心声增加时间，再压缩无信息的等待；不能牺牲笑点的“原因—反应”顺序。目标仍为约60–90秒，可依实测调整。
