# 第一集动作分镜 v2｜逐段视频提示词

对应32段动作分镜。生成时选取相应段落，配合该段独立首帧；不要把32段一起粘贴到一次视频生成请求。

每段中的时间窗口是动作目标，必须适配实际工作流原生帧率和允许帧数。仅首帧节点不支持强制尾帧；支持首尾帧时才输入尾帧。公开对白镜头本轮仅作无声表演测试，正式口型留待配音后校准。

## V01｜推纸触玉

首帧：K01S；尾帧目标：K01E。素材预算5秒，成片使用2秒。

机位：桌面特写；男主右手从画面右侧进入；固定。
起始状态：一张浅色约定纸正面朝上，位于桌中央偏男主一侧；实心浅青椭圆玉坠和旧红绳在纸右侧；一支黑笔在纸右下方。男主右手准备推纸，手腕尚未碰到玉坠。

结束状态：纸在两人之间平放；玉坠仍在纸右侧；右手停在纸边，黑笔未动。
此段有公开对白，允许说话表演；当前只测试表演，正式配音后再做口型校准。
